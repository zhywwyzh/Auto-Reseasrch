保留的候选工具

目标迁移判定与成本权衡。有限样本判定可支持评价；短期信号的长期预测价值和探测成本仍需实证。标准统计界不能独立承担论文创新。

LLM 提供候选，不作为收益真值来源。若随机生成配合同一选择器同样有效，应接受删除 LLM 的结论。

这轮需要形成的三种证据

  1. 形式证据：判据依赖什么假设，能够保持哪些任务依赖。
  2. 机制证据：依赖丢失是否导致迁移失效，简单规则能否解决。
  3. 系统证据：计全成本后，未见组合与留出任务表现是否改善。

从理论到实现的顺序

任务与指标→有限样本判定→短期/长期关联→等预算对照→冻结后复验

FORMALIZATION / CLAIM BOUNDARIES

先证明有限的事，
把无法保证的部分交给实验。

本节保留首轮迁移评价工具。最新建议先定义资源依赖及可计算判据，见复评中的理论设计；下述标准集中界不是论文核心创新。

推荐把理论组织成“问题定义 → 条件性准入界 → 预算与误判权衡”。标准集中界只是工具，论文贡献应在具体机制及它解决的问题。

1. 把环境、学习器与课程分开

目标任务族 M(ξ) 包含地图、PoI、无人机与充电配置，任务可按有限时域 Dec-POMDP 描述。策略 π 执行联合决策；训练状态 x 包括模型、优化器、归一化、缓冲区与随机状态。课程教师选择任务参数 z，学习算子 Ah(x,z;ω) 在 h 个全局环境步后输出新状态。

max课程规则 μ　E[JP目标(πxB)]
s.t.　C训练+探测+生成 ≤ B，　Vj(πxB) ≤ bjJ：归一化有效采集比例，取值 [0,1]；Vj：预先声明的违规/成本指标。B 可以是全局交互预算，墙钟和费用另行报告，不能未经权重定义直接相加。测试分布只用于最终报告。

这是研究目标的定义，不是已经求解的最优控制问题。有限样本评价只能支持分布意义的判断，不能证明每条无人机轨迹硬安全。

2. 定义“净迁移”，先排除额外训练的收益

πz,h = policy(Ah(x,z;ωz))
π0,h = policy(Ah(x,z控制;ω0))
Δh(z | x) = JP确认(πz,h) − JP确认(π0,h)

同一完整检查点、相同训练步数；控制分支继续学习固定原任务。先把两条训练轨迹固定，再讨论这两个策略的评价差异。若要声称“重新训练平均也有效”，还要在外层重复训练种子，不能靠多跑评价回合替代。

3. 草案命题：固定候选的有限样本准入

明确假设
  1. 本轮 K 对候选/控制策略已冻结；它们未利用本轮确认样本生成、更新或筛选。
  2. 对每对策略，n 个评价场景及随机数独立同分布抽自预先固定的 P确认。每个样本内部两策略使用相同场景，形成配对。
  3. 每回合主得分在 [0,1]，因此配对差 Dz,i 在 [−1,1]。不同候选可共享评价场景；不要求候选间独立。
  4. τ ≥ 0 是预先声明的最小有意义改善，不根据观察到的结果反向选择。
Δ̂z = (1/n) Σi Dz,i
r(n,K,δ) = √[2 ln(2K/δ) / n]
Lz = Δ̂z − r
接纳条件：Lz ≥ τ

能得到的结论：在上述条件下，以至少 1−δ 的概率，本轮所有被接纳的冻结策略对均有 Δh ≥ τ。它只对 P确认、当前检查点与短程训练后的策略成立，不保证未来训练、最终测试分布或重新训练的平均收益。

展开推导与适用边界

配对差范围长度为 2。Hoeffding 不等式给出 P(|Δ̂z−Δz|≥r) ≤ 2 exp(−nr²/2)。对 K 对策略取并集界，总失败概率不超过 2K exp(−nr²/2)。令其等于 δ，即得上式。该推导使用标准集中不等式，不是本文原创理论。

如果候选是在确认样本上选出来的，条件不成立；同一张固定地图的重复评价也不自动代表任务分布中的独立抽样。训练策略的随机性已被条件化，需要另外做独立训练重复。

多轮自适应选择可在每轮使用新的确认样本，并分配 δt=δ/[t(t+1)]。条件于过去，各轮仍需满足当前候选与新确认样本的独立性；再对轮次取并集界。反复复用相同确认集不能套用此论证。

如果还同时声明 G 个约束差异的界，需要将这些事件一起纳入失败概率分配。主得分改善不能推出碰撞率或耗尽率不变；约束差异也不等于绝对约束满足。

n ≥ ⌈2 ln(2K/δ) / ε²⌉。这是该保守界给出的充分数量，不是任何估计方法的必要下界；也不是训练种子数量。

5. 短期为何不等于长期

仅有 Δh > 0 不能推出 ΔH > 0。后续训练可能遗忘、过拟合、改变协作行为，或者让控制策略后来追上。

若另有假设 |ΔH − Δh| ≤ ε漂移
则 ΔH ≥ Δ̂h − r − ε漂移这是条件性推论。ε漂移目前未知；不能从同批训练数据估一个数，再称已获得无条件的长期保证。

第一项机制实验 E1 就是检验短期与长期的符号一致性、排序相关和错误接受率。若这个联系很弱，迁移探测的核心动机需要调整。

6. 成本使准入规则真正成为研究问题

候选数 K、探测长度 h、训练重复 q 和评价数 n 同时增加证据与开销。应先研究固定上限的选择规则，再考虑自适应分配；直接引入复杂 bandit 或贝叶斯优化会增加新的比较负担。

建议评价器先做启发式开发筛选，再对少数冻结候选用新样本确认；确认失败则回退。为了保留“所有候选同时有效”的论证，确认多候选时依实际 K 校正。与不用探测的方法比较时，允许对方将省下的步数投入训练。

理论定位建议

把有限样本界作为透明的判定依据，把“如何以有限成本选出有长期价值的 UAV 子任务”作为待验证贡献。暂不承诺通用 RL 收敛、全局最优或完备飞行安全。

一次迭代的设计伪流程

1. 冻结目标指标、允许参数、开发/确认/测试权限及本轮预算
2. 保存完整学习状态 x；由开发证据提出 K 个候选
3. 格式/必要可行性检查；unknown 不宣称已证明可行
4. 从 x 克隆：候选训练 h 步；控制训练 h 步；全分支记账
5. 开发筛选后冻结待确认策略；使用本轮新的确认样本
6. 按当前统计前提、约束和成本作准入决定；失败则回退
7. 保留胜出检查点（建议）；保存失败候选、依据与全部成本
8. 测试仅在完整方法及配置冻结后调用

如果更改为“只保留配置，再从统一检查点重训”，第 5 步对冻结策略的确认不自动适用于重训策略；需要重新评价，并计入重训成本。该实现选择会改变理论能支持的结论。
