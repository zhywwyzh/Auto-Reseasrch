怎样判断练习的迁移收益，
同时控制判断本身的成本？

主线保持方向 B。本轮提出一个可被淘汰的测量候选：复用练习训练前缀，用回训前后的配对测量估计完整课程配额的收益，并按相关性与真实成本决定是否使用校正。

最新准备进展：第一轮实验准备包已补充材料盘点、R0契约、最小诊断、独立确认成本和记录字段；尚未启动实验。

01　候选方案与改动边界

暂用内部标签 B-M（回训收益的多保真测量），不预先命名为已成立的新算法。它位于 4.2 的课程选择层：生成合法环境 → 比较候选配额 → 在选定配额上训练 → 原任务回训 → 反馈。4.3 学习规则、UCS 状态动作动力学、原奖励及 D/F/η/χ 均不改。

原 4.2 已有回训反馈（PDF105–106 / 印刷88–89），本轮不重复主张这一点。新增研究对象是同起点、同练习与回训时域下，替换课程配额的有限干预收益，以及测量这一收益的成本。不将候选比较解释为每个环境独立、可相加的贡献。

方法取舍：先保留无预测网络的统计测量版本，让公式与失效条件可检查；残差神经预测器仍是后续对照，不在本轮同时叠加。多保真控制变量本身是已有方法。只有领域机制、采样设计和实际净收益经强对照成立，才可能构成论文贡献。

延续 Auto Research 的实际使用：v3 任务契约约束修改范围，v2 先基线后机制，autoresearch 固定预算与简化规则，DISCERN 要求把失败条件写进结论。没有运行这些系统、研究 Agent 或付费模型。

02　候选是完整配额，不是假设可加的环境得分

固定含 J 个环境的合法池 ℰ={e₁,…,eJ}，基准配额 p₀ 为均匀分配。以预先冻结的 λ 构造 K≤J 个候选（预算中的 K 指候选配额数）：

pₖ = (1−λ)p₀ + λ eₖ，k=1,…,K。
例：J=4、λ=1/2，则 pₖ 对重点环境分配 5/8，其余各 1/8。
λ 是训练采样配额，不是奖励或原目标的权重。

这里 eₖ 在公式中是第 k 个单位向量。所有候选保留多任务训练；各候选总训练量 h 相同。若异步 actor 不能按此精确配额运行，应采用可实现的离散配额表并记录有效样本，不悄悄改变学生的更新规则。p₀ 与直接训练原任务都保留为对照。

设 s 为完整可恢复学习状态，Tₚ,h 为按配额 p 训练 h 步，Aₐ 为在原任务训练 a 步；ξᵢ 包含训练及独立评价的随机流。对每个训练重复 i 定义：

Xₖ,ᵢ = Eval(Tₚₖ,h(s); ξᵢ) − Eval(Tₚ₀,h(s); ξᵢ)
Yₖ,ᵢ = Eval(Aₐ(Tₚₖ,h(s)); ξᵢ) − Eval(Aₐ(Tₚ₀,h(s)); ξᵢ)
Uₖ = E[Yₖ,ᵢ]，U₀=0。
X：回训前较便宜的比较；Y：包含原任务回训的目标比较。

同一条练习分支先测 X，再从保存的训练状态继续回训得到 Y，形成嵌套样本。评价不得改变优化器、归一化、环境或随机源；回训前评价不应改变之后训练的边缘分布。候选与基准可以共享随机流，但每个候选自身的分布必须正确。

评价量与假设 A1–A5：不偷换原指标
  • A1：固定当前 s、候选池、h、a、评价地图分布及每分支评价回合数。
  • A2：不同 i 的完整训练/评价随机流独立同分布；同一个 i 的 X/Y 可以相关。仅重复评价同一参数不满足训练重复。
  • A3：E[X²]、E[Y²] 有限，方差非零。η 零分母与指标聚合口径先核验，不假定 χ∈[0,1]。
  • A4：β、n、m 预先固定，或仅由独立先导样本决定；正式样本不能再用于选 β、挑高分样本回训或反复查看后停止。
  • A5：Eval 使用原 χ 及冻结的原聚合规则。这里 U 是该评价协议输出的期望。若原规则先聚合再取比值，有限回合协议的期望不自动等于无限样本比值；本公式不消除评价器自身的有限样本偏差。

03　成对嵌套估计：均值可以不同，随机波动可以相关

下面暂省略候选下标 k。收集 n 个 X，其中预先选定的前 m 个继续获取 Y，n≥m。提出用于本课题的两层估计量：

(T1)  Û = Ȳₘ + β (X̄ₙ − X̄ₘ)
      E[Û] = U。

(T2)  Var(Û) = σY²/m + (1/m−1/n)(β²σX²−2βσXY)
      β* = σXY/σX²，ρ = σXY/(σXσY)
      Var(Û; β*) = σY²[(1−ρ²)/m + ρ²/n]。

来源边界：T1/T2 是经典控制变量 / MFMC 的两层形式在训练分支比较中的适配与重推，不是新发明的无偏估计器或新数学定理。无偏性不要求 E[X]=E[Y]，不要求低成本评价有已知的统一偏差上界，也不意味着无需昂贵 Y。

证明：为什么这个校正没有把即时目标偷偷替换成最终目标？

因为 X̄ₙ 和 X̄ₘ 均具有相同均值，校正项期望为零。记 d=1/m−1/n，由嵌套采样得到 Var(X̄ₙ−X̄ₘ)=dσX²，Cov(Ȳₘ,X̄ₙ−X̄ₘ)=−dσXY。展开平方得到 T2；对 β 求导得到 β*。独立先导样本条件下仍可逐条件使用这些结论。

若 β 估计错误，方差严格变为：

(T3)  Var(Û; β) = Var(Û; β*)
                      + (1/m−1/n)σX²(β−β*)²。

因此“用了校正”不等于“降低了方差”。先导数据太少、状态漂移或评价噪声都可能使校正更差。T3 的误差分解和后面的成本导数已做符号恒等式检查，未做模拟或训练。

两个不同的量，不能混淆：跨候选的均值排序是否翻转，决定即时选课是否有损失；同一候选内 X/Y 随训练重复的相关性 ρ，决定校正能否省测量。二者没有必然对应关系。示意 Xₖ=μₖ+Z、Yₖ=νₖ+Z 可同时具有不同均值排序和完美相关波动；这只是解析构造，不是 UCS 观测。

04　成本条件：相关性高还不够，先导和评价也要收费

cX 是一个成对 X 的完整成本；cA 是从其训练快照继续获得 Y 的增量成本；cH 是直接获得一个成对 Y 的实际成本。统一采用实际环境交互数为首轮预算单位，时间和费用另报。公式中的单价视为确定值或预先固定的成本上界；若采用平均单价，只得到期望预算关系，不能宣称硬预算保证。直接 Y 可以省去回训前评价，所以一般不能无条件写 cH=cX+cA。

(T4)  B = n cX + m cA，r=n/m≥1。
      Var(Û;β*) = (σY²/B) · F(r)
      F(r)=(cX r+cA)[(1−ρ²)+ρ²/r]。

0<ρ²<1 的连续解：
      r* = max{1, sqrt[cA ρ² / (cX(1−ρ²))]}。
内部解（r*>1）才有：
      F(r*)=[sqrt(cA(1−ρ²))+sqrt(cX ρ²)]²。

n>m 的必要最优条件是 ρ²>cX/(cX+cA)，但这只是“是否多取低成本样本”的条件。若总预算为 Btot，先导花费 Bpilot，直接 Y 对照不需要该先导，则理想校正胜过直接测量还要求：

(T5)  F(r*) / (Btot−Bpilot) < cH / Btot。
      实际判断还需加入 T3 系数误差、整数取整和共享基准成本。
等价地：Bpilot/Btot < 1−F(r*)/cH；右侧非正时不能节省。
本轮主动反证：R2示例不能作为一次性省预算方案。

在仅计训练、h=a、cX=h、cA=a、cH=h+a的理想情形，先导8×40k=320k，生产12×20k＋4×20k=320k，先导占两者总量的一半。即使 |ρ|→1，理想比值的下界也是 (cX/cH)×Btot/(Btot−Bpilot)=1；有限相关性、系数误差及回训前评价只会更不利。此推断限定于这里“独立先导不进入正式均值”的设计，不否定所有多保真方法。

因此R2只可作为测量机制诊断，不能拿它宣布端到端省预算。进入R3前须先给出可核的改进：减少先导开销，或在允许的信息范围内复用已有开发记录，并检验状态漂移和真实摊销成本。若研究交叉拟合以复用先导数据，需要另推相关方差并修改协议；本轮未把它加入既有保证。

推导与退回规则

把 m=B/(cXr+cA)、n=rm 代入 T2。对 F 求导得 F′(r)=cX(1−ρ²)−cAρ²/r²；限制 r≥1 后得到 T4。与方差 σY²cH/Btot 的直接测量比较得到 T5。ρ=0、零方差、|ρ|=1 等退化情形单独处理，不将连续极限当作可执行样本数。

参数未知时 T4/T5 只是设计依据；8 个先导重复也不足以保证精确估计相关性。若成本优势不明确，正式测量退回直接 Y，仍记录已经消耗的先导成本。单独报告“oracle β”分析上限，不能与可部署方法混在主结果里。

共享基准时不再把每个候选的成对成本简单相加。统一 n,m 的 K 个候选可共用一个参考分支，训练交互为 (K+1)(nh+ma)，其余评价另算；协方差需要保留。T4 的成对比例只作此共享设计的初始参照，不宣称是全局最优分配。

可交互的公式示意：不是实验数据

所有输入均为人为假设、同一种相对成本单位；输出是已知真实相关性和最优 β 的连续理想方差比，不是实测速度、置信度或部署保证。未计 β 误差、整数限制及跨候选共享。

05　从估计精度到选课：局部保证不冒充全程最优

本轮先用固定预算规则 k̂=argmaxₖÛₖ（包含 U₀=0，平局按固定顺序）。这是对当前 s 和有限候选池的决策；不在线自适应提前停止。令 k* 为真实最优候选，Δₖ=Uₖ*−Uₖ>0，vₖ=Var(Ûₖ−Ûₖ*)，则由单侧 Cantelli 不等式：

(T6)  P(k̂=k) ≤ vₖ/(vₖ+Δₖ²)
      E[Uₖ*−Uₖ̂] ≤ Σₖ:Δₖ>0 Δₖ vₖ/(vₖ+Δₖ²)。
      vₖ = Var(Ûₖ)+Var(Ûₖ*)−2Cov(Ûₖ,Ûₖ*)。

选到 k 意味着其差分估计噪声至少跨过 Δₖ；应用单侧界并按损失求和即可。它是标准统计不等式的适配；含未知真值和方差，不能直接变成可计算停止准则或非平稳课程的累计遗憾保证。共享基准的估计不独立；β 或样本数不同时，基准噪声也不一定完全抵消。

进一步发现：单个收益估计更准，仍不保证选课更准。若各候选 Yₖ=Uₖ+Z+εₖ 共用一个随机项 Z，去掉 Z 会降低每个候选的方差，但 Yₖ−Yₗ 本来就不含 Z。高相关性若主要来自共享基准，可能对区分候选没有帮助。因此本候选优先控制差值方差，不只报告单候选MSE。

T7：共享系数的差值校正——本轮更具体的候选设计

用独立先导样本选定一个比较中心 j（先导回训收益最高的配额，含基准0），并冻结比较集合 ℘={(k,j):k≠j}。首轮权重 wₖⱼ=1，不再调权。所有候选采用相同 n、m 和一个共享 β，使参考项在任意候选对相减时保持一致。对每个比较对定义 Dˣₖⱼ=Xₖ−Xⱼ、Dʸₖⱼ=Yₖ−Yⱼ。

A = Σ℘ wₖⱼ Var(Dʸₖⱼ)
B = Σ℘ wₖⱼ Var(Dˣₖⱼ)
C = Σ℘ wₖⱼ Cov(Dˣₖⱼ,Dʸₖⱼ)
Q(β) = Σ℘ wₖⱼ Var(Ûₖ−Ûⱼ)
     = A/m + (1/m−1/n)(β²B−2βC)
(T7) βgap* = C/B，ρeff²=C²/(AB)≤1
     Q* = A[(1−ρeff²)/m+ρeff²/n]。

A、B、C 在本段是协方差汇总量，与方向编号或总预算符号不同。T7由T2逐比较对加权相加后配方得到；C²≤AB由Cauchy–Schwarz给出。它仍是标准二次优化的任务化推导，不宣称新控制变量定理。B=0时不校正；A=0时没有需要降低的差值方差。

具体方法差异：普通逐候选MFMC选择各自的βₖ来减小Var(Ûₖ)；B-M拟采用同一βgap来减小与先导领先候选的差值方差总和。实际βgap由独立先导估计，不能假装已知。T4可用ρeff与整组候选的增量成本计算配额比例，优化的是固定℘下的Q，不是真实误选概率或全程收益。先导中心选错、系数估计不准和状态漂移均可能失败。

这是本轮明确提出、需要反证的设计点。必须比较逐候选MFMC、共享但按单值方差拟合的β、差值βgap与通用多输出控制变量；若后者与本设计等价，就将它视为已有方法的适配，不凭重命名宣称创新。

拟议流程（设计说明，不是研究实现）

  1. 从经过 R0 验证的状态 s 分支，固定候选完整配额、h、a 及评价器。
  2. 用独立先导分支记录 X/Y、成本及协方差；冻结比较中心j、是否启用校正、共享βgap、n、m。先导不混入正式估计。
  3. 新随机流收集 n 条练习前缀，按预先规定的索引将 m 条继续回训。禁止观察 X 后只延长高分分支再套 T1。
  4. 计算各候选Û，选定一个已经直接测试的完整配额；不把候选均值做 softmax 后组成未经测试的新混合。
  5. 主学习器从共同起点用新的训练随机流执行选定配额及固定原任务回训；不挑选探测中的幸运 checkpoint 当成主分支。
  6. 按预先固定的少数测量时点重复，探测期间消耗计入总预算。未测量的时点沿用上一配额或基准，规则在比较前冻结。

若想发展按候选差距分配核验量，可在下一阶段提出独立先导选择的固定分配方案，再与等额分配竞争；本轮不同时承诺最优保真度、最优候选分配和全程最优课程。

06　创新论点：可争取的三项，不能宣称的五项

拟争取的贡献需要的证据不足以支持它的材料
C1：识别原 UCS 中回训改变完整课程配额价值的条件与实际损失短窗诊断＋原时域确认；跨种子阶段与任务；区分训练噪声只有二次目标反例或翻转次数
C2：复用训练前缀、面向候选差值的外层测量设计，减少可靠选课所需成本同预算直接Y、同标签预测、逐候选及多输出MFMC；差值/单值系数、先导与共享基准消融仅套用T1/T2，或只与即时X比较
C3：不改原任务与骨干，在完整生成训练流程中实现净收益全部交互等预算、真实时间/费用、独立任务留出、原4.2重建离线估计误差变小或只在单个快照获胜

不能宣称：首次回训反馈、首次控制变量、首次多保真选臂、首次在RL中降方差、T6证明完整课程最优。C2 是当前风险最高的一项；通用 MFMC 已能覆盖大部分设计时，应承认它是适配基线，而不是改名当新算法。

9.3 把问题写成一次公平比较

  3. 冻结选择结果，用新的训练与评价随机流从原快照重新运行{kX,kY,p₀}的去重集合；不挑筛选中的幸运checkpoint继续。确认时只评价回训后结果，不再选优。

9.6 怎样决定继续、简化或停止

先确定原χ量纲下的最小实际有意义差值δχ，再冻结分析计划。它是研究判断尺度，不改变环境成功条件或训练奖励；数值依据尚不足，当前保留待定。不得观察正式确认结果后倒选δχ。评价精度与训练随机性分别规划，多评价回合不能替代多训练种子。

  • 继续方向：原定义与恢复契约通过，独立确认支持回训后选课有实际收益，且不是单个阶段或种子的偶然现象；再进入原240k/240k时域核验，不能用短窗替代。
  • 简化路线：即时评价已足够，或同标签简单预测器已解决问题，就不强加B-M。
  • 保留未决：区间过宽或样本太少。R1-P不作总体推断；3主种子的R1-S也只是探索，不能承诺统计功效。“不显著”不等于“等效”。正式样本量、区间及多重比较方案在独立开发后、确认前冻结，不反复查看结果追加样本。
  • 停止相应分支：收益独立确认消失、仅是近乎平局的错序，或完整成本不划算。B-M先导成本和近邻等价问题未解，暂不进入它的完整收益验证。
