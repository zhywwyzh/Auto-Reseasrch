D0 · 标准对偶工具的直接推导；用于P0修复，不算创新

弱松弛：从任意合法旋转候选构造可审计次优界

假设：M=Mᵀ；Rᵢ严格满足SO(3)；矩阵和目标按上面的未缩放定义计算。若实现有归一化、常数或量测权重，须同步变换所有上下界。

命题：令Bᵢ=Rᵢᵀ(RM)ᵢ、Λᵢ=Sym(Bᵢ)，S=M−Diag(Λᵢ)。若可信误差界证明S⪰−εI，ε≥0，则0≤f(R)−f*≤3Nε。若ε=0且所有可行性精确成立，R为原SO(3)问题全局最优。

展开证明、来源及适用边界
  1. 弱SDP对偶为max ΣᵢtrΛᵢ，约束M−Diag(Λᵢ)⪰0，Λᵢ为对称矩阵。任意可行对偶值都不超过原SO(3)最优值，不需要先假设强对偶。
  2. 上述Λᵢ总是对称，且ΣtrΛᵢ=Σtr[Rᵢᵀ(RM)ᵢ]=f(R)。注意这只是迹恒等式，不表示非驻点候选自动满足矩阵互补条件。
  3. 把每个Λᵢ替换为Λᵢ−εI₃，可使对偶松弛变为S+εI⪰0；因此L=f(R)−3Nε是合法下界，U=f(R)是合法上界。
  4. 在旋转驻点处Skew(Bᵢ)=0，并有(RM)ᵢ−RᵢΛᵢ=0；一般候选不具有该等式。若S⪰0且⟨S,RᵀR⟩=0，则PSD互补性反过来推出SRᵀ=0。
  5. 若候选只近似正交，不能直接用U作原问题可行上界；必须先恢复合法候选并重新计算目标。浮点特征值输出也不自动等于可信ε。

边界：该推导避免依赖有争议的局部扰动分解，但没有修好原文先验噪声定理。即便3Nε很小，也只证明原目标次优界，不证明相对真值误差小。

来源：原预印本PDF5–7 / 印刷5–7，式(14)、(17)–(19)和Theorem1。Sym后与原驻点乘子写法一致；原定理没有因此被整体否定。

D1 · 标准锥对偶推导；用于强基线的正确认证

强松弛：新增手性约束的乘子必须进入证书

假设：将每个conv(SO(3))约束写为Hₑ(X)=I₄+𝒜(Xᵢⱼ)⪰0，其中𝒜取ICCV2025给出的线性映射；𝒜的具体符号和比例与所用实现保持一致。

命题：若Zₑ⪰0且S_C=M−Diag(Λᵢ)−Σₑ𝓛ₑ*(Zₑ)⪰0，则L_C=ΣᵢtrΛᵢ−ΣₑtrZₑ为下界；𝓛ₑ(X)=𝒜(Xᵢⱼ)，*表示相对于迹内积的伴随。对原SO(3)可行候选仍以原目标f(R)作上界。

展开证明、来源及适用边界
  1. 拉格朗日函数为⟨M,X⟩+Σ⟨Λᵢ,I−Xᵢᵢ⟩−Σ⟨Zₑ,I₄+𝓛ₑ(X)⟩。整理得到⟨S_C,X⟩+ΣtrΛᵢ−ΣtrZₑ。
  2. 对X⪰0求下确界：S_C⪰0时为常数项，否则无有限下界；因此Zₑ和S_C的半正定性都必须检查。
  3. 若Zₑ已经合法而S_C⪰−εI，则同样将Λᵢ减εI₃，下界减少3Nε。若Zₑ本身不合法，不能只修S_C；须先修复Zₑ并重算S_C与对偶值。
  4. 强松弛求解后若仍检查M−Λ而漏掉新增乘子，可能拒绝本来可认证的候选；也不能把另一问题的对偶值与原目标上界拼接。

边界：这里只给出认证规格，未实现求解器或浮点验证器；不同LMI的常数项改变时，应使用−Σ⟨Zₑ,H₀,ₑ⟩而不是盲用−ΣtrZₑ。

来源：ICCV2025 Anisotropic Rotation Averaging，PDF6 / 印刷14861的SDP-C SO(3)与4×4 LMI；本轮重新读取该段。

D2 · 本轮条件化推导；很可能是已有强松弛的直接图论推论，不认领原创

无噪充分条件：加强生成树即可，不必加强所有块

假设：无噪且观测图连通；选定加强边C含一棵生成树T；对T中每条边rank(Aₑ)≥2。其他边只需保留原PSD残差，不要求它们也被加强。

命题：选择性强SDP具有唯一最优Gram矩阵X₀=(11ᵀ)⊗I₃，秩为3。该充分条件不要求原弱证书矩阵在规范补空间有正谱隙。

展开证明、来源及适用边界
  1. X₀可行且无噪代价为0。任何PSD可行X的每条边残差贡献都是非负，因此零总代价意味着每条树边贡献为0。
  2. 树边的贡献为Fₑ(X)=2tr[Aₑ(I−Xᵢⱼ)]。由Xᵢⱼ∈conv(SO(3))，写成若干合法旋转Q的凸组合；每个旋转在至少两条独立方向上的残差均非负。
  3. 凸组合的边代价为0，迫使所有正权重Q固定这两条方向；SO(3)保持叉积，故Q=I，进而Xᵢⱼ=I。
  4. 将X写成X=YᵀY，Y=[Y₁,…,Y_N]、YᵢᵀYᵢ=I。若Xᵢⱼ=I，则‖Yᵢ−Yⱼ‖²_F=6−2trXᵢⱼ=0。沿生成树传播得全部Yᵢ相等，所以全部块Xᵢⱼ=I，唯一性成立。

边界：这里只证明无噪Gram恢复。不能从唯一性直接推出带噪SDP仍秩3；也不能推出完整6DoF精度、安全或求解速度。生成树并非所有几何下的必要条件。

来源：原无噪Gram结构：学位PDF115–116 / 印刷87–88；conv(SO(3))加强来自ICCV2025。矩阵加权网络的生成树条件已有成熟近邻。

D3 · 本轮解析命题；用于构造精确基线和否决泛化主张

共同平面特例：加强边连通是必要且充分的

假设：无噪；原图连通；每条边Aₑ的像空间都是同一二维平面，且rank(Aₑ)=2；仅在观测边C上增加conv(SO(3))约束。

命题：强SDP唯一恢复X₀，当且仅当(V,C)连通。因此最少需要N−1条加强边；若只最小化非负可加的边约束成本，问题就是最小生成树。这不是实际求解时间最优的保证。

展开证明、来源及适用边界
  1. 把共同平面取为span(e₁,e₂)。任意零代价PSD可行X=YᵀY在原图每条边上都满足Yᵢe₁=Yⱼe₁、Yᵢe₂=Yⱼe₂；连通性使前两列在所有节点间相同。
  2. 每个Yᵢ第三列为与前两列正交的单位向量uᵢ。因此所有零代价解可写为Xᵢⱼ=diag(1,1,Gᵢⱼ)，其中Gᵢⱼ=uᵢᵀuⱼ，G⪰0且Gᵢᵢ=1；反向构造也成立。
  3. 对加强边，diag(1,1,Gᵢⱼ)∈conv(SO(3))迫使Gᵢⱼ=1，否则无法由同时固定e₁、e₂的合法旋转凸组合得到。Gᵢⱼ=1等价于uᵢ=uⱼ。
  4. 若加强图连通，所有uᵢ相同，G=11ᵀ，X=X₀。若不连通，可以对不同加强连通分量取u或−u，得到另一个合法零代价Gram解；更一般的分量向量还可形成高秩解。

边界：共同平面假设是关键。在方向各异的带环图中，原弱松弛可能已经唯一；不能将本命题的连通必要性推广到一般图。可加边成本也只是选边目标，不代表SDP运行时间可加。

来源：本轮在D2和前轮桥反例上推导；精确原创性尚未排除。它会作为无需复杂选择器的强基线。

D4 · 本轮手工推导稿；标准旋转恒等式、凸组合及图谱界的组合，不认领首创

量化引理：加强边把二维方向约束变成全帧一致性能量

假设：沿用无噪M₀及已对齐坐标；对加强边定义κₑ=tr(Aₑ)−λmax(Aₑ)，即Aₑ最小两个特征值之和。选定κₑ>0的加强边形成连通图；Lκ为其标量加权Laplacian，λ₂(Lκ)>0。

命题：对任意选择性强SDP可行X，有F₀(X)≥[λ₂(Lκ)/2]tr(PX)，其中P=(I_N−11ᵀ/N)⊗I₃。若带噪M=M₀+Δ、‖Δ‖₂≤δ，X*是同一选择性强SDP的精确最优解，则tr(PX*)≤12Nδ/λ₂(Lκ)，并且X*最大的3个特征值之外的特征值之和不超过该界。

展开证明、来源及适用边界
  1. 对Q∈SO(3)，用轴角表示得tr[A(I−Q)]=(1−cosθ)(trA−uᵀAu)≥κ(1−cosθ)=(κ/2)(3−trQ)。该线性不等式对Q的凸组合Y同样成立。
  2. 因此加强边Fₑ(X)=2tr[Aₑ(I−Xᵢⱼ)]≥κₑ(3−trXᵢⱼ)=(κₑ/2)‖Yᵢ−Yⱼ‖²_F。求和并使用标量加权Laplacian的Poincaré界，得F₀(X)≥[λ₂(Lκ)/2]Σ‖Yᵢ−Ȳ‖²_F；后者的平方和就是tr(PX)。
  3. 所有可行X均有trX=3N，故|⟨Δ,X⟩|≤3Nδ。由带噪最优性F_M(X*)≤F_M(X₀)，且F₀(X₀)=0，得到F₀(X*)≤6Nδ。结合上一不等式得到所述12Nδ/λ₂(Lκ)界。
  4. I−P是秩3的正交投影。由PSD矩阵的最大三特征值和的变分表述，Σ_{k>3}λ_k^↓(X*)≤tr(PX*)。这只是尾谱大小界，不要求也不能推出尾谱严格为0。
  5. 若求解器返回SDP可行的X̃且具有已知的SDP目标次优界η≥0，则同样推导得到tr(PX̃)≤(12Nδ+2η)/λ₂(Lκ)。η必须有合法SDP上下界支持，不能从停止标志猜出。

边界：这是粗的分析界，不是带噪精确紧性定理，也不是旋转/平移真值误差界。D5给出基于已知有界方向误差的一条可计算替代路径，但可能无效或非常保守。新稿若仅把λ₂(Lκ)拿来选边，会与MAC和既有谱设计高度重叠。

来源：本轮推导；图谱部分与矩阵加权一致性、MAC/OASIS路线有直接近邻，须进一步比较。

D5 · 本轮手工推导；标准块范数、Weyl与D4的组合，作为可计算基线

从有界方位误差得到可计算的粗界：仍然不等于新理论

假设：准确旋转里程计；每个方向向量的确定性欧氏误差≤ξ；Dᵢ是节点i参与的边—时刻观测数，Dmax=max Dᵢ，mₑ是边e的观测时刻数。无界高斯噪声不能直接满足该确定性前提。

命题：一般加性有界误差下令a=2ξ+ξ²，有‖M−M₀‖₂≤β=2Dmax·a。若测得和真实方向均已单位归一化，可以取a=2ξ、β=4Dmaxξ。选一个端点的本地对齐方位构造Âₑ，令tₑ=mₑa、κ̲ₑ=max{0,trÂₑ−λmax(Âₑ)−2tₑ}。若选定边上的L_{κ̲}满足λ₂>0，则D4的尾谱上界可用12Nβ/λ₂(L_{κ̲})替代真值依赖表达式。

展开证明、来源及适用边界
  1. 对一个方向g=g₀+e，‖ggᵀ−g₀g₀ᵀ‖₂≤2ξ+ξ²。对一对方向的交叉块，也由展开得相同上界a。若观测和真值都为单位向量，用乘积差的望远镜展开可将两类界同时降为2ξ。
  2. 把ΔM的3×3块范数组成非负对称比较矩阵。每次与节点i相连的观测至多向其对角块及一个非对角块各贡献a，因此块范数行和≤2Dᵢa。对称比较矩阵的谱范数不超过最大行和，得β。这个界针对数据矩阵M，不是未经处理的对偶矩阵S。
  3. 用边e一个端点的准确里程计将方向转到该端点固定局部参考系，构造Âₑ。其理想矩阵与真值公共系Aₑ仅差正交相似变换，所以特征值相同；且矩阵扰动范数≤tₑ。由Weyl，最小两个特征值之和的差不超过2tₑ，因此κ̲ₑ≤κₑ。
  4. Lκ−L_{κ̲}⪰0且二者共享常量零空间，故λ₂(Lκ)≥λ₂(L_{κ̲})。将β及κ̲代入D4即可得到可计算但可能很保守的尾谱界。需要已知且有效的ξ，不能把平均误差、实验观测到的最大值或测试真值当成传感器保证。
  5. 若该上界≥3N，则相对trX=3N没有有效尾谱信息；若κ̲图不连通，则此充分条件无法给出界。两种情况都不等于估计必然失败。即使界很小，也不能宣称尾谱严格为0。

边界：这补上了D4的一条简单可计算路径，但没有证明实际定位精度、精确秩紧性或新方法优势。κ̲与β的构造使用常规扰动不等式；若论文只到这一步，应作为分析工具，而非独立创新。未知里程计、标定、对应和时钟误差尚未纳入。

来源：基于原预印本PDF5–6的数据矩阵定义、本轮D4，以及标准谱扰动与块范数比较；待独立复核。

优先反证：树形图可能没有选择性加约束的节省空间

本轮手工分析草案，待独立复核；不是原创性声明，也不是实验结果

无噪、准确旋转里程计、每条树边对齐方向张成二维空间；仅允许在已观测边的Gram块上增加conv(SO(3))约束。选择一个所有真实旋转均为I的合法实例族即可检验普遍节省主张。

任取未加强的树边并断开它。以该边方位平面为镜面，把不含固定规范机器人的一侧全部机器人旋转变量同时左乘对应反射F。内部边两端一起变化，零残差不变且内部相对Gram块仍为I；跨断边的方向被F固定，残差也为0。但跨边相对变换为反射。若该边未受手性约束，弱松弛仍保留这个非法物理解。

在这类树上，每条边都需要被加强才能排除这种反射族。因此不能预设‘总能只加少量观测边约束’。若允许非观测边约束，一个跨割约束可能改变结论，必须重新定义设计域；带环、含噪或高秩情形也需另证。

04 / 方法流程与接口规格

步骤动作边界
1 / 输入与候选读取当前方位和里程计窗口，构造原目标及一个SO(3)可行候选测试真值不进入估计、调度或候选筛选
2 / 认证检查计算当前松弛下的完整上下界、数值可行性和时间开销通过表示给定目标的差距满足要求，不代表真值误差一定小

07 / 时间、样本与预算

理论优先：P0/P1先花约8–15个工作日做准入，不预先承诺后续大规模试验。时间均为规划估计，不是实际耗时或交付保证。

排错起步包建议6个结构实例×2种噪声条件×2个种子=24份日志，只用于发现实现/假设错误；4个核心估计方案对应96次顶层运行，不含局部法内部起点。该规模不是统计功效设计。

原噪声主组在P0核定后锁定；额外角扰动压力组可先用0°、1°、3°，须明确定义单位球面生成过程并换算误差界，不能与原高斯σ或ξ混称。

先用获准的排错运行测出每方法的时间分布，再预算正式试验：总开销为各实例各方法时间之和，不能直接用最便宜方法的均值乘次数；失败/超时和多起点也计费。

正式测试数量根据预设主要配对比较、开发集方差/二元不一致率与置信区间宽度制定。按独立场景分组，不能把同轨迹连续帧当独立样本；所有精度非劣效界与最小实际收益在看测试结果前冻结。

若1名研究者已有可用代码和平台，完整路线可按约8–12周估算；新定理、原代码缺失或实机排期都可能显著延长。先通过每个阶段的去留检查，再投入下一阶段。

建议时段工作交付
第1–2个工作日完成任务合同与版本差异；锁定噪声、里程计、变量和原目标输出可审查的假设清单，未知项标明而不擅自补定义
第3–4个工作日重推全局对偶和数值上下界；复核两机器人/树形解析例子输出原保证修订说明和证书协议
第5–7个工作日完成ICCV2025直接适配、AutoTight映射和桥/环反证；对照2026近邻输出已有方法可覆盖范围与剩余候选结论
第8–10个工作日写T1–T3定理卡片、最小方法流程和E0/E1配置规格，作去留判断输出明确的继续/收窄/停止建议；复杂证明未完成则保持待证，不按日历强行宣布通过
