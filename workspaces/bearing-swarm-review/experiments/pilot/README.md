## 固定范围

`protocol.json` 是先导配置；它不是论文留出测试协议。先执行数学接口检查和故障注入，再跑6类×4个坐标变换的24个诊断。全部通过后，才生成 N=4/8、树/环/稠密、平面/近共面/三维的18个开发世界，各有0/1/3度球面帽噪声，共54条日志。每条日志跑弱SDP、观测边加强、全对加强、确定性生成树加强和几何初始化NLS。另用1e-7容差复查每类一个诊断，保留30次重复记录；NLS重复不代表它的精度参数改变。

主目标为原稿PDF5、式(6)/(8)/(14)的未缩放方位残差平方和，每个无向边/时刻计一次。Python用堆叠残差构造 `A.T @ A`，Julia独立累加四个端点块构造M；检查器再按原始方向重算候选目标。全对加强和观测边加强分别报告。

世界中的位置按10控制点线性插值得到100时刻；机器人姿态在各自轨迹中固定，因此旋转里程计是**精确单位矩阵**。这是一种合法但简化的旋转子问题输入，不代表已覆盖旋转里程计变化、里程计误差、平移恢复、动力学、碰撞、FoV或闭环规划。观测图是人为测量掩码，不声称自然可见性。真值和位置只进入生成器和评测器，不传给Julia求解器或NLS初始化。

## 实现与检查

- `model.py`：诊断/开发数据生成，单位球面帽噪声，观测生成树Wahba初始化与SO(3)最小二乘。
- `solver.jl`：JuMP/SCS弱/强SDP；输出原始Gram、全部对偶乘子、原始状态和目标。
- `checker.py`：独立重建M、原始残差、四元数LMI伴随、完整对偶松弛与常数；PSD修正后的数值下界；反射/输入校验。**全部是浮点检查，无严格认证。**
- `run.py`：门槛、24诊断、精度复查和54日志；逐次保存矩阵、候选和失败。断图/共线不报告不可辨识的全局旋转误差。
- `analyze.py`：描述性汇总和科学绘图；D5界的有效域检查明确标为探索性分析。

conv(SO(3))采用独立实现的标量优先四元数矩LMI，与已审查的[ICCV2025固定提交](https://raw.githubusercontent.com/ylochman/anisotropic-ra/f0ede76128edd893e2fa5a5727b6b94de44bc1be/anisotropic_ra/anisotropic_ra.jl)中的LMI经坐标变换等价；没有沿用其SfM目标或将此标准加强约束认作新方法。对偶实现参照[JuMP锥约束说明](https://jump.dev/JuMP.jl/stable/manual/constraints/)。本轮没有执行上游完整代码，不能称为精确复现。
