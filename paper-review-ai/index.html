目录规则
上游浅克隆位于本目录 upstream/，由 Git 忽略；保留来源、版本和许可证。默认稀疏检出，省略根目录 data/datasets/checkpoints/model_weights；不下载 LFS 内容或单独模型权重。
本页、清单及收集脚本可以由 Git 跟踪；论文原文和上游副本不上传。公开源码与权重、开源许可范围分别记录。

恢复与使用边界

重新克隆本仓库后，可运行 python3 paper-review-ai/fetch_sources.py --fetch 恢复记录版本的阅读副本。普通运行仅重建本页。现有副本不会被自动更新或重置。

尚未安装依赖、下载独立模型权重、执行研究实验或付费评审；源码下载不是效果复现。
