# 论文评审公共工具源码

本目录的上游代码以普通文件纳入主仓库，不建立独立 Git 仓库、子模块或远端。
上游链接、固定版本和逐文件 SHA-256 统一记录在 `external/sources.lock.json`。
许可证及版权声明保留原件；纳入源码不改变其许可或证明评审效果。

离线核对：`python3 paper-review-ai/fetch_sources.py`。该入口只验证已有源码，
不克隆仓库、不执行上游项目、不安装依赖或调用模型。

`.gitignore` 为逐文件允许清单。原有公开数据集、原论文、模型权重、结果、
运行记录和未审查文件继续留在本地忽略区；实际研究任务同样不进入 Git。
